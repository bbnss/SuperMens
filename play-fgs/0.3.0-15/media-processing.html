SuperMens: Local audio processing

FOREGROUND_SERVICE_MEDIA_PROCESSING — Google Play Console use case: Other.

Direct video link (MP4)

What the recording shows

The user selects a synthetic WAV audio file in the Android file picker. SuperMens starts local transcription. The user goes to the Android Home screen and opens the notification panel. The visible notification says “SuperMens is processing Audio”. The user returns to SuperMens, where the imported audio and ongoing transcription are shown.

Recorded on 30 October 2026 using an Android 16 x86_64 emulator and an isolated debug build of SuperMens 0.3.0 (15), package com.bbnss.SuperMens.emulatordemo, from the app's release-candidate sources. The model and application processing are real; no inference, progress or notification is simulated. Only synthetic input is used. These clips demonstrate initiation and ongoing foreground work, not end-to-end completion or device performance. The original screen recording is preserved; the published MP4 contains only its video track.
